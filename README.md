# OMD domain icons

Icons for data domains in the Trans.eu Group OpenMetadata catalog, served via jsDelivr:

```
https://cdn.jsdelivr.net/gh/szymczyklp/omd-domain-icons@v1.0.0/icons/<name>.svg
```

Temporary public hosting; the icons will move to company infrastructure.

- Pictograms: [Lucide](https://lucide.dev) v0.460.0, ISC license (see `LICENSE-lucide`).
- Company marks (Pactus, EITD, TransCash, Bonabanco) belong to the respective companies of Trans.eu Group and are used for internal cataloguing only.
